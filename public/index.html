Mock CRM & Receivables REST API Explorer

This mock ERP serves as the data source for downstream AI recovery agents. All endpoints are fully functional, return standard JSON, and can be queried directly from your Python, LangChain, or Node.js applications.

Base URL: http://localhost:3000/api
GET /api/invoices/overdue

Returns all overdue receivables with calculated days_overdue, customer preferred communication tone, preferred language, and risk profile.

# Python Example for AI Agent:
import requests
response = requests.get('http://localhost:3000/api/invoices/overdue')
overdue_invoices = response.json()['data']
GET /api/customers

List all 32+ B2B customers with aggregate balance metrics, late payment count, and tone preferences. Supports query params: ?search=, ?tone=, ?language=, ?risk=high.

GET /api/customers/:id

Returns comprehensive profile of a customer including all their invoices, payment histories, behavioral assessment, language, and communication tone.

GET /api/customers/:id/invoices

Returns all invoice records associated with a specific customer ID.

GET /api/customers/:id/payments

Returns historical payment transactions for a customer.

GET /api/invoices

Query all invoices with filters: ?status=PAID|OVERDUE|PENDING|PARTIALLY_PAID, ?sort=amount|due_date.

POST /api/invoices/:id/payments

Record a payment received from customer. Automatically recalculates balance and updates status to PAID or PARTIALLY_PAID.

GET /api/dashboard/stats

Aggregated KPIs for financial health, total overdue sum, and aging breakdown.
